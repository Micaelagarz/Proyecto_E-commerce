🥜 Dietética Online

Aplicación web desarrollada como proyecto personal con el objetivo de simular un e-commerce de productos naturales y saludables. El proyecto fue creado para fortalecer conocimientos de desarrollo frontend, consumo de APIs, manipulación del DOM y diseño responsive.

📋 Descripción

La aplicación permite a los usuarios explorar un catálogo de productos, visualizar información detallada, agregarlos a un carrito de compras y gestionar los productos seleccionados de forma dinámica.

Los productos son obtenidos mediante una API, simulando el comportamiento de una tienda online real.

🚀 Tecnologías utilizadas
HTML5
CSS3
JavaScript (ES6+)
Fetch API
Git
GitHub
Swiper.js
✨ Funcionalidades
Catálogo dinámico de productos.
Consumo de API mediante Fetch.
Visualización de imágenes, precios y descripciones.
Carrito de compras.
Modificación de cantidades.
Eliminación de productos del carrito.
Cálculo automático del total de la compra.
Interfaz responsive para dispositivos móviles, tablets y escritorio.
Navegación fluida mediante secciones.
